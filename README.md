# 我从零学 Python 的练习记录

## day2 ~ day6：语法基础

学习 Python 中变量定义，条件判断（if），循环使用（for、while，其中还有区别 C 的自增减的使用 i+=1），然后是用以上知识做的累加器，最后学习了长度、最大最小值、求和函数（len、max、min、sum），加一个列表定义。注：这里面还有（try 和 except）

## day7 ~ day10：列表、函数、字典、文件

学习列表的升降序排列【sorted()】，切片取出【scores[:3]】，定义自己的函数（def），字典的使用，文件读写

## day11 ~ day13：JSON 与命令行通讯录

用 JSON 将字典或列表存文档，制作命令行通讯录，功能如下：

1. 按下 1 时进入输入模式，输入“名字+电话号码”将存入专属列表
2. 按下 2 时进入查找模式，输入名字或电话号码就能找到对应的电话号码或名字
3. 按下 3 时将目前存入文件的内容全部展示出来
4. 按下 4 时进入删除模式，目前只能输入目标人物名字才能进行删除
5. 按下 0 时结束，内容更新进专属文件
6. 每次启动程序会从文件读取已经存入的内容，在输入上有错误时会有提醒

## 怎么跑

```
python day13.py
```
